About OddsMind

Prediction markets are usually a destination. OddsMind treats them as a data source: a research desk that reads Panta's markets, explains what the price is saying, and hands the same intelligence to agents through an API.

What it does

  • Pulse — the whole Panta catalog, enriched with each market's trade tape: implied odds, activity, volume, wallets, concentration.
  • Market brief — one page per market: live odds and source, price history reconstructed from trades, a fill-depth ladder quoted live from the bonding curve, top holders, resolution details, and an AI brief that combines the market data with fresh web context.
  • Ask — a plain-words question becomes an answer grounded in the markets that actually address it.
  • Wallet lens — any Solana wallet's Panta positions, current value, claimable winnings and trading style.
  • Embeds & API — a live market card for any site, and JSON for every view so bots and agents can use market intelligence too.

How the Panta API is used

Panta endpointUsed for
GET /markets/Discovery — the full USDC catalog, paginated by cursor.
GET /markets/{id}/Market detail: phase, spot prices, oracle, creator, times, on-chain program and creation signature.
GET /markets/{id}/trades/The trade tape — reconstructs price history (USDC ÷ shares per fill), 24h activity, YES/NO flow, holder concentration.
POST /primaryorderquote/Fill depth — read-only quotes for $10/$50/$250 on each side. A quote session opens; no transaction is ever built or signed.
GET /positions/?wallet=Wallet holdings with valuation, claim eligibility and outcomes.
GET /wallets/{wallet}/trades/Wallet trade history and per-market activity.
GET /categories/Category allowlist for filters.

One honest note: catalog rows for markets created inside the Panta app currently come back with an empty title. OddsMind resolves those titles from the market's public page on panta.market and caches them, and every response says where the title came from (titleSource). Prices likewise state their source — Panta spot when the API returns one, otherwise the last trade on the tape, otherwise “no price data”. Nothing is simulated or made up.

Built with

A single Cloudflare Worker (static assets + JSON API), a KV cache, Panta's public API, and Gemini for the analyst layer with web grounding. No wallet connection, no keys in the browser, no trades placed. Source: github.com/zxreigns/oddsmind.
