OddsMind API

Every view in OddsMind is backed by a JSON endpoint you can call from your own agent, bot or dashboard. No key needed; responses are cached briefly and always attribute Powered by Panta.

Base URL: this site. CORS is open. Rate limits are shared and modest — cache on your side. Under the hood each call fans out to Panta's public API (live-api.panta.market/api/v1) with a server-held key.

Endpoints

EndpointWhat it returnsPanta calls behind it
GET /api/pulseThe whole catalog enriched: resolved titles, implied YES/NO, trade counts, 24h volume, wallets, holder concentration, plus totals and category counts.GET /markets/ (paginated), GET /markets/{id}/trades/ per market
GET /api/markets?category=&phase=&q=Filtered subset of the pulse.same
GET /api/market/{id}Market brief data: detail, price + source, tape stats, price series, top holders, live fill depth, last 60 trades.GET /markets/{id}/, GET /markets/{id}/trades/, POST /primaryorderquote/ ×6
GET /api/market/{id}/briefThe AI analyst's brief (headline, read, flow, context with sources, catalysts, risks, confidence).same + web search
GET /api/market/{id}/depthFill ladder only ($10/$50/$250, YES and NO).POST /primaryorderquote/
GET /api/market/{id}/tapeRaw trade tape (up to 200 rows).GET /markets/{id}/trades/
GET /api/wallet/{address}?ai=1Positions with current value and claimable flags, trade history, per-market activity, YES/NO bias; ai=1 adds a style profile.GET /positions/?wallet=, GET /wallets/{wallet}/trades/
GET|POST /api/ask?q=Natural-language question → relevant markets + a plain-words answer with odds.pulse
GET /embed/{id}An embeddable market card (iframe) with live odds.detail + tape
GET /api/healthVersion and configuration state.—
